# Tugas Struktur Seleksi 03 - Pengecekan Bilangan Prima

Repositori ini berisi proyek sederhana dalam bahasa C++ sebagai contoh implementasi dari struktur seleksi. Program ini bertujuan untuk menentukan apakah sebuah bilangan yang dimasukkan oleh pengguna merupakan bilangan prima atau bukan.

---

## Fitur Utama

* **Input Pengguna**: Program meminta pengguna untuk memasukkan sebuah bilangan bulat.
* **Pengecekan Bilangan Prima**: Melakukan validasi untuk menentukan apakah bilangan yang dimasukkan adalah bilangan prima.
* **Output Hasil**: Memberikan output yang jelas kepada pengguna, yang menyatakan apakah bilangan tersebut prima atau bukan.

---

## Teknologi yang Digunakan

* **C++**: Seluruh logika program ditulis dalam bahasa C++.

---

## Prasyarat Instalasi

Untuk dapat menjalankan proyek ini, Anda memerlukan C++ compiler yang sudah terpasang di sistem Anda, seperti:
* [GCC (GNU Compiler Collection)](https://gcc.gnu.org/)
* [MinGW](http://www.mingw.org/) untuk pengguna Windows
* [Clang](https://clang.llvm.org/)

## Contoh Penggunaan

1.  **Clone repositori ini:**
    ```sh
    git clone [https://github.com/azaniahmad/tugas-selection-structure-03.git](https://github.com/azaniahmad/tugas-selection-structure-03.git)
    ```

2.  **Masuk ke direktori proyek:**
    ```sh
    cd tugas-selection-structure-03
    ```

3.  **Kompilasi file C++:**
    ```sh
    g++ TugasSelectionStructure.cpp -o BilanganPrima
    ```

4.  **Jalankan program:**
    ```sh
    ./BilanganPrima
    ```

5.  **Ikuti instruksi di terminal** untuk memasukkan sebuah bilangan dan lihat hasilnya.

    **Contoh Sesi:**
    ```
    Masukkan sebuah bilangan: 7
    7 adalah bilangan prima
    ```
    ```
    Masukkan sebuah bilangan: 10
    10 bukan bilangan prima
    ```
